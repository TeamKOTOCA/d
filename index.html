d

cd/lsの進化系インタラクティブディレクトリナビゲーター

機能

ディレクトリ移動支援

ディレクトリを簡単に移動

ページ分割表示

多数のサブディレクトリを1ページ10件で整理

超軽量

数十行の.shなので凄く軽量。

動作環境

標準的なUNIX/Linux環境で動作します：

  • OS: Linux, macOS, WSL(Linuxのみ確認済み)
  • Shell: bash (推奨), zsh (動作すると思われます)
  • 依存コマンド: ls, sed, wc, read

※ インストールスクリプトはデフォルトで bash/zshを見分けて設定しますが稀にうまくいかないことがあります。

インストール

ターミナルで以下のコマンドを実行してください：

curl https://d.kotoca.net/set.sh | bash

インストール後、設定を反映します：

source ~/.bashrc

使用例

$ d
Current: /home/user/projects
Page 1 / 3
--------------------
0) .. (parent)
1) backend
2) frontend
3) docs
4) scripts
5) tests
6) tools
7) config
8) data
9) logs
--------------------
0-9=select, n=next, p=prev,Enter=quit

使い方

  • d - 現在ディレクトリのサブディレクトリ一覧を表示
  • 0-9 - 数字キーでディレクトリを選択して移動
  • n - 次のページを表示
  • p - 前のページを表示
  • Enter - 終了
