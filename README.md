# d - ディレクトリ移動支援ソフト

**`d`** は、ターミナル上で簡単にディレクトリを一覧表示し、ページごとに移動できる便利なシェルスクリプトベースのソフトウェアです。  
特に大量のフォルダがあるディレクトリでの移動操作を効率化します。

---

## 概要

- ディレクトリをページ単位で表示（1ページあたり10件）
- `n` / `p` で次ページ・前ページに移動
- 数字を入力するとそのディレクトリに移動
- `Enter` でスクリプトを終了
- `..` は親ディレクトリとして特別表示

## 動作環境
- Linux
- Bash
